## 软件简介

晚的空间（wan-Space）是一款面向 Android 平台的数字工具箱，集功能工具、网站发现、资源导航与自由社区于一体。应用坚持“高效、简洁、还有质量”的设计原则，为用户提供清晰、顺手、可持续扩展的使用体验。

> “我只想多见你一次，多和你说一句话。”
> 晚的空间，欢迎每一个晚归的你。

## 核心功能

### 首页 Home

- 每日一言：每日更新一句内容，提供轻量阅读入口。
- 网页发现：收录有趣、实用的网站，拓展发现入口。
- 日常工具：整合常用功能，提供快捷访问。
- 更多功能持续开发中。

### 工具 Tools

- 功能合集：功能、游戏、网站集中直达。
- 导航：按影视、小说、漫画等分类整理。
- 资源网盘：集中分享优质资源。
- QQ 社区：提供自由交流的社区入口。

### 收藏 Star

- 支持一键收藏常用工具。
- 可随时浏览、管理与再次访问。
